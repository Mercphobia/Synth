## CLI Commands Summary

```
synth "task"                        # One-shot agent run
synth chat                          # Interactive REPL
synth cost [--today|--month]        # Token/cost report
synth best-of-n "task" --models a,b # Best-of-N selection
synth doctor                        # Environment health check
synth init [--force]                # Generate AGENTS.md
synth config path|get|set           # Config editing
synth scan [PATH] [--markdown]      # Security audit
synth session search "query"        # FTS5 session search
synth session export <id>           # Export session
synth snapshot create|list|restore  # Session snapshots
synth git status|diff|commit|log|review
synth models list|available|install|uninstall|status
synth task list|create|status|delete
synth cron add|remove|list|enable|disable|run
synth daemon start|stop|status
synth serve                         # JSON-RPC server (for TS CLI)
synth-tui chat                      # TypeScript Ink TUI
synth-tui run "task"                # TS one-shot via RPC
synth-tui status                    # Check runtime
```

## Flags
```
--mode plan|act|auto|architect      # Agent mode
--godmode                           # Disable all safety boundaries
--caveman                            # Terse output compression
--no-rtk                             # Disable RTK shell filter
--no-stream                          # Disable streaming
--checkpoint TAG                     # Create checkpoint before run
--undo                               # Undo last session step
--swarm                              # Enable multi-agent supervisor
--model MODEL                        # Override config model
--resume ID                          # Resume session
--verbose                            # Debug logs
```

## Exit Codes
```
0=success  1=general  2=arg  3=config  4=llm  5=tool
6=security  7=sandbox  8=permission  9=cancelled
```
